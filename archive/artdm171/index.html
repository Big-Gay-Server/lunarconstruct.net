My Career Goals

Goals

My career goals aren't much, at the moment! I am only recently starting to really get into Graphic / Web Design, so I'm still learning how the industry works. As for my more short term goals, I take part in a couple of creative, storytelling projects. I want to be able to make websites to showcase and advertise these projects!

Knowledge of Web Design

I have never created a site completely from scratch before! Until now, I have been using free website creation programs like Wix and Weebly! I had been using these programs for 5-6 years. I have used HTML in the past, as well as CSS (although only briefly). I was never formally taught how to use them, though, so I am mostly self taught. I don't have an extensive knowledge on how web design and HTML/CSS coding works, but that is why I am taking this class! I want to learn as much as I can.

What I Wish to Learn

In this class, I would love to learn about the industry around Graphic / Web Design, as well as actually learning how to make your own site from scratch. Things like how to get jobs in the field, and other things that could help a newcomer into the field! As for design-wise, I want to learn about smart / efficient ways to set up a website, and keeping the site simple / easy to navigate but still unique!
